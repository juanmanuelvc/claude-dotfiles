Launch parallel Explore agents (thoroughness: "very thorough") to analyse this
repository, then generate `docs/repo-overview.md` containing:

1. **Purpose** — what the project does in 2–3 sentences.
2. **Architecture** — ASCII diagram of the main modules and their relationships.
3. **Stack** — languages, frameworks, key libraries and their versions.
4. **Entry points** — main startup, config, and build files.
5. **Data flow** — how data moves end-to-end through the system.
6. **Detected conventions** — naming patterns, directory structure, code style.
7. **Tests** — how to run them, what coverage exists, known gaps.
8. **Technical debt** — list of TODO/FIXME/HACK comments found in the codebase.

After writing the file, print a one-paragraph summary of the most important
findings so I can decide what to tackle first.
